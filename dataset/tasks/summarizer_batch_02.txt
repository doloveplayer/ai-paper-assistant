II. RELATED WORK
A. Object Detection
Object detection in computer vision can be categorized
into one-stage and two-stage methods. One-stage detectors
such as SSD [10], RetinaNet [11], and the YOLO series
provide fast results by directly extracting object classification
and bounding box information from feature maps. On the
other hand, two-stage detectors such as the Faster-RCNN
[12] do region proposals to increase accuracy at the cost
of additional processing time. Recently, a transformer-based
framework called DETR [13] was introduced, which considers
object detection as a set prediction issue and simplifies the
detection process.
Two-stage networks generate remarkable detection accuracy
but suffer from poor real-time performance due to extensive
computations, while one-stage algorithms provide higher real-
time performance with simplicity and efficiency. YOLOv5 also
emerges in terms of efficiency. As we mentioned Yolo famillies
utilize a one-stage architecture, resulting in faster inference
times compared to two-stage detectors. This efficiency is
critical for resource-constrained devices or applications.
III. METHOD
In this study, we emphasize optimizing the feature extrac-
tion process, as capturing more discriminative features from
input images can significantly improve detection accuracy
in challenging conditions. Unlike other approaches that in-
corporate additional modules, such as image restoration or
domain adaptation techniques, we avoid these due to their
high computational cost and complex architectures, which
are unsuitable for real-time applications on resource-limited
devices. Our network leverages the MobileViTv2 (MV2) block
and an Inverted Residual structure to enhance computational
efficiency, reducing overall complexity while maintaining ro-
bust accuracy. Additionally, the C3RFE (C3 with Receptive
Field Enhancement) module enriches feature maps by applying
multi-rate dilated convolutions, which expand the receptive
field to capture multi-scale contextual information essential
for detecting obscured objects in foggy images. The overall
structure of our network is depicted in Fig. 1.

General object detection: Object detection [44] is one of the
fundamental tasks and research topics in the ﬁeld of com-
puter vision, whose goal is to locate a target object in natural
images and recognize its category. The two main challenges
of this task are the vast range of intra-class variations and
the huge number of object categories. To solve these chal-
lenges, existing methods are focused on learning the dis-
criminative feature representations based on deep learning
techniques. Based on the workﬂow of the existing models,
we can roughly divide them into two branches: One branch
is the two-stage based models, whose representative works
include Faster-RCNN [2] and Mask R-CNN [1]. Their work-
ﬂow is ﬁrst to extract the object candidates via a region pro-
posal network, and then train the object classiﬁer based on
the object proposals. Although two-stage based models
have achieved satisfactory performance, they require con-
siderable computational resources, which limits their appli-
cation range. To improve the efﬁciency, one-stage based
object detection models are introduced, which correspond
to the second branch on object detection. The representative
works include SSD[3], YOLO [4], and FCOS [5], which aim
to directly detect the objects without extracting any object
proposals. Compared with two-stage based models, these
one-stage methods suffer from some performance degrada-
tion, especially on small objects detection. Nonetheless, in
the presence of adverse weather conditions, the perfor-
mance of existing object detectors from both branches gets
degraded due to corruption of the images taken in the wild.
Causal Inference. Causality [46], [47] has led to new meth-
odologies for improving the generalization and trustworthi-
ness of deep models. It has been widely explored in the
ﬁeld of computer vision, including image classiﬁcation [33],
[48], visual question answering (VQA) [49], [50], [51], zero-
shot visual recognition [52], long-tailed image recognition
and segmentation [53], [54], [55]. Most of those methods
focus on discovering causal effects via causal intervention.
Speciﬁcally, Zhang et al. [55] have used the backdoor adjust-
ment to remove the confounding bias, which introduces
pseudo-masks as the groundtruth annotation for weakly

causal effect and to remove the bias caused by the con-

1.3. Current Study
From the explanation above, we have concluded that the dataset and its components
are numerous. Nevertheless, every dataset was annotated according to their requirements
and failed to cover all of the aspects of weather conditions from a unique study. Therefore,
choosing a few helpful images and merging them to cover all of the weather features in a
single dataset for feeding into a neural network was an acquisitive aim. Additionally, we
combined the ACDC and DAWN datasets (some example images are presented in Figure 1),
which practically cover all adverse conditions, excluding direct sunshine, i.e., sun glare.
Still, the unique and accurate annotation for the combined dataset was the biggest hurdle
for this work. It was unable to combine the labeling, since the various datasets utilize
various methods to annotate their datasets. The goal was to develop a quick and efﬁcient
approach for annotating the combined data as per the needs of object detection. Before that,
knowing each dataset’s labeling procedure and strength for network training was useful
for subsequent research.
Since this investigation was limited to 2D object detection through image data from
camera sensors, the primary proposition of this work was to use the YOLO as an object
detection method. As discussed above, a few researchers have used the YOLO method for
object detection in autonomous driving. Some have tried to modify the method to boost
performance (e.g., IA-YOLO, YOLO-R, DE-YOLO, Gaussian-YOLOv3, etc.). Refs. [64,65]
discussed the network architectures, challenges, advantages, applications, and many more
for different versions of the YOLO method. Recently, ref. [66] published the most updated
information about the YOLO algorithm and discussed all the YOLO version releases until
the most recent version (YOLOv8, [67]). Previously, ref. [68] performed work on object
detection in bad weather for autonomous driving, but the work has several limitations.
Ref. [68] suggested training a custom model using the YOLOv5 to detect objects in adverse
weather. Just one model was trained in 18 min and 12 s using 239 images downloaded
from the Roboﬂow website, and it reached an accuracy of about 25%. Comparatively, our
work proposed assessing the feature merging between two datasets to open up additional
prospects for combining more datasets, and, in some cases, we achieved a more than 90%
accuracy utilizing the YOLOv8.

the distant area, as shown in the red region in Fig. 1(a). This
characteristic is referred to as the intrinsic property of point
clouds, which is “Near is dense, and far is sparse”. Therefore,
establishing a unified denoising framework to enhance the data

4.2. Deraining Subnetwork
Rain streaks can reduce the discriminative capacity of different objects’ features. In
the real world, rain streaks block some of the light reﬂected by objects, which reduces
images’ contrast and brightness. In addition, rain streaks appear as noise in images and
will reduce signal-to-noise ratio of original images. To alleviate the problem, we proposed
a Deraining Subnetwork, which reduces the noise in features by reconstructing rain-free
images. Figure 2 shows its architecture, which consists of two modules, namely a derain-
ing feature extractor φderain() and a rain-free image generation module. To successfully
perform the subsequent weight-sharing strategy ColTeaching, φderain() shares the same
structure as the detection feature extractor, which consists of the ﬁrst two convolution
blocks in the DroneDet Subnetwork. Features φderain(R) are delivered into the rain-free
image generation module for image deraining.
